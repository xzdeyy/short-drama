# 短篇与微型连续短剧节奏规则

用于 `single_film`、`micro_series`、`short_series`。

## 一、单篇动画：3–6 分钟

目标：一条成片内完成完整故事。

### 推荐节奏

- 前 5–15 秒：钩子 / 异常 / 冲突前置
- 15–60 秒：建立人物、欲望、关系与问题
- 60–150 秒：冲突升级，因果开始反噬
- 150–240 秒：关键误会、真相或反转出现
- 240–330 秒：高潮与选择
- 最后 20–40 秒：结局、回收与余味

具体比例必须服从故事，不机械卡点。

## 二、微型连续短剧：2–5 集

默认每集 120 秒，允许 90–150 秒。

每集至少要完成：

1. 一个明确目标
2. 一次有效冲突
3. 一项信息或关系推进
4. 一个阶段结果
5. 末集外可保留自然钩子

### 禁止恶意卡断

禁止：

- 一句话说到一半切集
- 一个动作举到一半切集
- 真相已经明确却为了下一集故意不说完
- 靠重复前情拖时长

允许：

- 新事实出现后切集
- 人物做出关键决定后切集
- 门被打开 / 人物现身 / 证据出现后切集
- 一个阶段目标结束、下一阶段即将开始时切集

## 三、短篇连续剧：6–12 集

每集约 1–3 分钟。

结构上可设置阶段目标，但仍不强制长篇付费短剧的卡点密度。

## 四、因果规则

优先使用：

- 因此……
- 但是……
- 所以……
- 没想到……

减少纯“然后”。

每个关键 Beat 都应回答：

- 这件事为什么发生？
- 它导致了什么？
- 人物因此做了什么新选择？

## 五、时长估算

时长由表演决定，不由字数决定。

估算时同时考虑：

- 台词正常语速
- 动作完成时间
- 停顿和情绪反应
- 镜头建立空间的时间
- 关键特写和反转留白

不要以“800 字 = 一集”之类规则硬推时长。
