# 题材指南

本 Skill 不再把题材限制为传统长篇付费微短剧。题材用于帮助确定世界、冲突与观众预期，**不得覆盖用户已经锁定的剧情**。

## 题材使用规则

1. 选择 1 个主题材 + 0–2 个副题材。
2. 最多 3 个标签。
3. 创作来源与题材分开记录：例如“原著改编”是来源，“古代志怪”才是题材。
4. 用户脑洞与原著核心高于题材模板。
5. 不要求每种题材都必须有传统反派、感情线或爽点。

## 核心题材库

### 1. 都市情感
现代关系、爱情、婚姻与情感博弈。

### 2. 霸道总裁
身份差、权力差与强关系冲突为核心的都市爱情。

### 3. 甜宠
以情感互动、反差与高糖关系推进为主要观看价值。

### 4. 重生穿越
通过时间、身份或世界变化重新面对命运。

### 5. 战神 / 强者归来
隐藏身份、实力反差、归来与保护关系。

### 6. 古装宫廷
宫廷、权谋、后宫、皇权与家族博弈。

### 7. 励志逆袭
人物从低谷通过能力、选择和代价完成逆转。

### 8. 家庭伦理
家庭关系、婚姻、代际冲突、利益与人情。

### 9. 萌宝 / 亲子
孩子作为关系核心、情感纽带或剧情推动者。

### 10. 悬疑探案
谜团、线索、嫌疑、调查与真相揭露。

### 11. 软科幻
以轻度科技 / 超常设定服务人物关系与冲突。

### 12. 末日生存
灾难、生存压力、资源、群体关系与选择。

### 13. 喜剧
反差、误会、荒诞、嘴贫、黑色幽默或生活喜剧。

# 新增：古代 / 志怪 / 寓言方向

## 14. 古代志怪

**一句话描述：** 古代日常生活中闯入狐、鬼、妖、异术、怪事，以“异”照见人的欲望与情感。

**适合：** 聊斋改编、志怪原创、古代奇闻、狐鬼情缘、人性故事。

**核心要素：**

- 先有人间生活，再有异事
- 异类有明确规则，不是随意法术
- 奇异事件最终落在人情、人性、欲望、因果上
- 不必有传统 Boss
- 不强制法术大战

**常见副标签：** 情感、悬疑、凄美、讽刺、喜剧、人性寓言。

**示例分类：**

- 《莲香》：古代志怪 + 情感 + 悬疑
- 《酒虫》：古代志怪 + 黑色寓言 + 喜剧 / 讽刺

## 15. 民间奇谈

**一句话描述：** 民间口耳相传式的怪事、禁忌、风俗与地方传说。

**重点：**

- 地域生活质感
- 简洁明确的禁忌规则
- “听起来像真事”的叙述感
- 结尾可留余味

## 16. 黑色寓言

**一句话描述：** 用荒诞、反噬或极端选择讽刺贪欲、虚荣、偏见与人性弱点。

**重点：**

- 人物往往自己推动灾祸
- 结局应回扣前面的欲望或选择
- 可搞笑，但笑点最后要服务于讽刺

## 17. 古代悬疑

**一句话描述：** 古代环境中的谜团、失踪、身份错位、秘密与调查。

**重点：**

- 线索必须提前存在
- 反转不能凭空出现
- 可与志怪叠加，但需区分“真异事”与“人为谜局”

## 18. 人性寓言

**一句话描述：** 通过一个高度集中、具有象征性的事件观察人的欲望、选择与代价。

**重点：**

- 故事可很小
- 人物不必多
- 结局强调因果与余味
- 不强求爽点

# 题材叠加建议

| 组合 | 适合方向 |
|---|---|
| 古代志怪 + 情感 | 狐鬼情缘、人与异类关系 |
| 古代志怪 + 悬疑 | 身份谜团、规则揭秘 |
| 古代志怪 + 黑色寓言 | 欲望反噬、因果讽刺 |
| 民间奇谈 + 悬疑 | 禁忌、传闻、村镇怪事 |
| 古代悬疑 + 喜剧 | 荒诞公案、误会破局 |
| 家庭伦理 + 黑色寓言 | 家产、偏心、贪欲反噬 |
| 都市情感 + 喜剧 | 现代恋爱脑洞、职场关系 |

# 创作来源与题材的区别

正确：

```text
创作来源：原著改编
原著：《聊斋志异·莲香》
主题材：古代志怪
副题材：情感 + 悬疑
```

错误：

```text
题材：聊斋改编
```

“聊斋改编”描述的是素材来源，不是故事的叙事类型。

# 出海模式

原有都市、霸总、甜宠、重生、家庭、悬疑等题材可继续做文化映射。

古代志怪出海时，可根据故事实际情况映射为：

- Supernatural Folklore
- Ghost Story
- Folk Horror（仅在确属恐怖取向时）
- Supernatural Romance
- Dark Fable
- Historical Mystery

映射只改变表达与文化包装，不自动改变 `mustKeep`、人物关系或结局。
